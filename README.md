# 每日工作台

一個純靜態的每日工作頁面：今日任務、本週行程、快速筆記、習慣打卡與飲水提醒。資料只存於瀏覽器 localStorage，無需登入或後端。

## 使用方式

直接用任何靜態伺服器開啟本目錄即可，**不需 npm / 建置步驟**。

例如：

```bash
# Python
python3 -m http.server 8080

# 或 npx（可選）
npx serve .
```

然後開啟 `http://localhost:8080/`。

亦可直接用瀏覽器開啟 `index.html`（部分瀏覽器對 `file://` 的 localStorage／Service Worker 行為可能不同，建議用靜態伺服器）。

## 啟用 GitHub Pages

1. 將此資料夾推送到 GitHub 倉庫（例如倉庫名 `daily-work`）。
2. 倉庫設定 → **Pages** → Source 選 **Deploy from a branch**。
3. Branch 選 **main**，資料夾選 **/ (root)**，儲存。
4. 數分鐘後網站會出現在：

**https://tommyt852.github.io/daily-work/**

（路徑需與倉庫名稱一致；本站使用相對路徑 `./styles.css`、`./app.js`、`./sw.js`，適合 project Pages 的 `/daily-work/` 子路徑。）

## 功能摘要

- **今日任務**：新增、完成／取消完成、刪除、拖曳或按鈕排序；顯示尚餘數量；可帶入昨日未完成項目。
- **優先級與標籤**：每項任務可設優先級（高／中／低，預設中）與短標籤（例如「工作」「私人」）；可按優先級及／或標籤篩選今日清單；新增時或於任務列即可編輯。
- **本週行程**：一週日曆條；新增／編輯／刪除定時行程。
- **快速筆記**：草稿自動儲存；可存成筆記；Enter 快速新增。
- **習慣打卡**：新增／刪除習慣；以香港時區日期打卡；顯示本週（一至日）圓點進度。
- **飲水提醒**：使用瀏覽器 **Web Notifications API**（於 Windows 的 Chrome／Edge 會以 Action Center／系統 toast 顯示）。可啟用／關閉，間隔 30／45／60／90 分鐘（預設 60）。啟用時會請求通知權限；若被拒會顯示清楚說明。附有小型 service worker，有助於分頁開啟或縮到工作列時顯示通知。
- **飲水提醒限制（請留意）**：此站為純靜態頁、**沒有推播伺服器**。關閉分頁或瀏覽器後就不會再提醒；僅在頁面（或已註冊的 service worker 仍受控）執行期間依間隔通知，並避免短時間重複發送。
- **示範資料**：首次開啟會載入示範內容；可用「清除示範資料」一次清空本機資料。
- **匯出／匯入 JSON**：可下載完整備份（`daily-work-YYYY-MM-DD.json`，匯出格式版本 2），或以檔案還原；匯入前會確認並以新資料「取代」本機內容。舊版（缺少優先級／標籤／習慣／飲水設定的檔案）仍可匯入，缺欄位會使用預設值。格式錯誤會提示，不會令頁面崩潰。
- **時區**：Asia/Hong_Kong；介面為繁體中文（香港）。
